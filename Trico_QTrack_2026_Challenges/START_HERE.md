# Tri-Co Hackathon 2026 — Quantum Track Challenges

**Bi-Co Quantum Computing Club**

Welcome to the QTrack coding challenges. Explore quantum computing through four progressively more advanced Jupyter notebooks. Each level contains background concepts, programming tasks, examples, self-checks, and short explanation questions.

## Getting started

1. Download this ZIP and extract its contents.
2. Open `notebooks/00_Orientation_and_Setup.ipynb` in [Google Colab](https://colab.research.google.com/) and run it to set up your environment.
3. Open the Level 0 notebook and continue through Levels 1–3 as your team progresses. Each challenge notebook also includes a setup cell, so notebooks can be run independently.
4. Complete the `TODO` functions, run the self-checks, and answer the written questions in the notebooks.
5. Save your completed notebooks with outputs and figures visible. See `resources/SUBMISSION_GUIDE.md` for a simple completion checklist and file-naming suggestions.

For a local Python environment, install packages with `python -m pip install -r requirements.txt` and open the notebooks in Jupyter or VS Code.

## Challenges

| Level | Topic | Main skills |
|---|---|---|
| 0 | Quantum Circuits & Measurement | Gates, basis states, superposition, measurement statistics |
| 1 | Entanglement & Correlations | Bell and GHZ states, measurement bases, correlation patterns |
| 2 | Grover Search | Phase oracles, diffusion, amplitude amplification |
| 3 | Quantum Noise & Mitigation | Noisy simulation, readout errors, data analysis, visualization |

All challenges use Python and local quantum simulators. They do not require paid quantum hardware.
